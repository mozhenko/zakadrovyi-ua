# Закадровий UA — озвучення відео українською

Розширення для Chrome (Manifest V3), яке читає субтитри відео українським голосом поверх оригіналу, як закадровий переклад. Працює на YouTube, а на інших сайтах — якщо в плеєрі є субтитри.

Версія 1.1.0 · ліцензія MIT · безкоштовно, без реклами й без збору даних.

## Встановлення

1. Розпакуйте архів `zakadrovyi-ua.zip` у постійну папку (наприклад, «Документи/Розширення/zakadrovyi-ua»).
2. Відкрийте в Chrome адресу `chrome://extensions`.
3. Увімкніть **Режим розробника** (перемикач праворуч угорі).
4. Натисніть **Завантажити розпаковане** і виберіть папку `zakadrovyi-ua`.
5. Закріпіть значок розширення на панелі (іконка-пазл → шпилька).

Відкрийте будь-яке відео на YouTube — озвучення почнеться автоматично.

## Два режими

**Субтитри YouTube** (найпростіший). Розширення бере субтитри відео (авторські або автоматично згенеровані), просить YouTube перекласти їх українською і читає переклад голосом.

**Власний переклад.** Розширення бере оригінальні субтитри, склеює рядки в цілі речення і перекладає їх обраним сервісом:

| Перекладач | Що потрібно | Якість |
|---|---|---|
| Google Перекладач | нічого, безкоштовно | добра |
| DeepL | API-ключ (безкоштовний план — 500 000 символів/міс.) | дуже добра |
| Claude | API-ключ Anthropic | найприродніша: виправляє помилки автосубтитрів, враховує контекст, робить фрази стислішими для озвучення |

Якщо платний сервіс недоступний, розширення тимчасово перемикається на Google і повідомляє про це у статусі.

## Голос

- **Авто** — системний український голос, якщо він є, інакше онлайн-голос Google.
- **Системний** — голоси, встановлені в ОС. На macOS: *Системні параметри → Спеціальні можливості → Озвучений вміст → Голос системи → Керувати голосами → Українська* (Lesya; варіант «Enhanced» звучить помітно краще). На Windows: *Параметри → Час і мова → Мовлення → Додати голоси*.
- **Google (онлайн)** — голос Google Перекладача, працює скрізь, потрібен інтернет.

Кнопка «Прослухати голос» дає змогу порівняти варіанти.

## Синхронізація зі звуком

- Кожна фраза починає звучати в момент своєї появи у відео.
- Якщо переклад довший за оригінал, голос плавно прискорюється (до ×1,7), щоб не відставати; фрази, що запізнились більш ніж на 4 с, пропускаються.
- Під час мовлення оригінальна доріжка плавно приглушується (повзунок «Оригінал під час мовлення»), а в паузах повертається — класичний закадровий принцип.
- Пауза, перемотування, зміна швидкості відео і реклама обробляються автоматично.

## Інші сайти

На сторінці з відео (Vimeo, TED, освітні платформи, власні плеєри) увімкніть субтитри в плеєрі, відкрийте розширення і натисніть **«Озвучити відео на цій сторінці»**. Працює там, де субтитри підключені як стандартні HTML5-доріжки; відео всередині сторонніх iframe недоступні.

## Гаряча клавіша

**Alt+Shift+U** — увімкнути / вимкнути озвучення. Змінити: `chrome://extensions/shortcuts`.

## Якщо субтитри не завантажуються

З 2026 року YouTube захищає запити субтитрів спеціальним токеном. Розширення отримує його з запиту самого плеєра (для цього воно на мить вмикає й вимикає субтитри). Якщо статус просить «Увімкніть субтитри (CC)», натисніть кнопку CC у плеєрі — розширення підхопить субтитри саме.

## Обмеження

- Відео без субтитрів (ні авторських, ні автоматичних) озвучити не вийде: тут потрібне розпізнавання мовлення, це окремий етап розвитку.
- Google Перекладач і голос Google використовують неофіційні точки доступу; при дуже інтенсивному використанні Google може тимчасово обмежувати запити.

## Конфіденційність

Розширення не має власного сервера й нічого не збирає. Налаштування зберігаються в браузері. Ключі API (DeepL, Claude) зберігаються лише локально й надсилаються тільки відповідному сервісу. Під час роботи тексти субтитрів надсилаються сервісу, який ви обрали для перекладу (Google, DeepL або Anthropic), а при онлайн-голосі Google — ще й сервісу озвучення Google.

```

background.js         голос, переклад, гаряча клавіша
offscreen.*           відтворення онлайн-голосу
shared/settings.js    налаштування за замовчуванням
content/inject.js     перехоплення запитів субтитрів плеєра YouTube
content/core.js       фрази, синхронізація, приглушення, накладка з текстом
content/youtube.js    логіка для YouTube
content/generic.js    логіка для інших сайтів
popup/                спливаюче вікно налаштувань
```
